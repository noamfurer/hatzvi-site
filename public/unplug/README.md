# ארץ הצבי · נותנים לילדים לגדול

מיני-סייט לקהילת ההורים, שיושב בכתובת `hatzvi.site/unplug`.
נבנה ב-Next.js 15 כאתר סטטי (static export), עם React 19, Framer Motion ופונט Rubik שמתארח באתר עצמו.

## הרצה ובנייה

```bash
npm install
npm run dev      # פיתוח: http://localhost:3000/unplug
npm run build    # בנייה: התיקייה out/ מוכנה להעלאה
```

## העלאה לשרת

- **אותו שרת של hatzvi.site:** מעלים את **התוכן** של `out/` לתיקייה `unplug/` בשרת. הקבצים כבר בנויים לנתיב `/unplug`.
- **Vercel / Netlify:** מחברים את הריפו. פקודת הבנייה היא `npm run build` ותיקיית הפלט היא `out`. אם האתר יושב בשורש של דומיין (ולא ב-`/unplug`), בונים עם `NEXT_PUBLIC_BASE_PATH="" npm run build`, ומעדכנים את `siteUrl` בקובץ `content/config.ts`.

## עריכת תוכן (בלי לגעת בעיצוב)

| מה | איפה |
|---|---|

| לוגו, דמות הצבי, תמונת שיתוף | `public/img/`, `public/og.jpg` |

## חיבור טופס האמנה ל-Google Sheets

1. פועלים לפי ההוראות שבראש `apps-script/Code.gs`, כ-5 דקות עבודה.
2. מדביקים את כתובת ה-Web App בשדה `formEndpoint` בקובץ `content/config.ts`, ובונים מחדש.
3. עד שהכתובת מוגדרת, כפתור השליחה מוסתר ובמקומו מופיעה ההודעה "ההרשמה תיפתח ממש בקרוב".

**מד ההצטרפות** מוצג רק כשקיימים נתונים אמיתיים, ורק אחרי שמוסיפים בסקריפט את המאפיין `PUBLISH_COUNTS=true`. המד מציג רק מספר משפחות לפי שכבה, בלי שמות.

## החלטות שכדאי להכיר

- **סימולציית הוואטסאפ** מציגה בכל סבב 2–3 הודעות מקטגוריות ומערים שונות. 16 ההודעות הקשות ביותר (תוכן מיני, אלימות, סחיטה) מסומנות ב-`SEVERE`. הן לא מופיעות בשלושת הסבבים הראשונים, ואחר כך מופיעות בהסתברות של 30%. ההודעות לא מתחלפות כשהסימולציה לא נראית על המסך, ויש כפתור עצירה.
- **נגישות:** כיווניות RTL מלאה, ניווט מקלדת, מצבי Focus ברורים ותוויות ARIA. האתר מכבד את ההגדרה Reduced Motion, ואין בו צלילים או הבהובים.
- **מקורות:** ההמלצות לגילים 9–11, 13 ו-15 והנתון 16.3% (סקר HBSC 2025) לקוחים מכתבת ynet מ-3.9.2026 על המלצות משרד הבריאות. מומלץ להחליף לקישור למסמך הרשמי ב-gov.il כשיהיה זמין.
- **מדריכי ההגדרות** של Apple ו-Google אומתו מול דפי העזרה הרשמיים, כולל שמות התפריטים בעברית לפי iOS העדכני. את שלבי הוואטסאפ לא ניתן היה לאמת אוטומטית מול מרכז העזרה שלו, ולכן כדאי לעבור עליהם פעם אחת בטלפון.
